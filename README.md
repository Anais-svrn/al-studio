# al-studio

Application mobile AL STUDIO : dressing intelligent, looks, météo, calendrier et gestion du dressing.

## Aperçu

Cette application est un prototype mobile-first en HTML/CSS/JS, conçu pour fonctionner comme une PWA (Progressive Web App) sur navigateur mobile ou ordinateur.

## Déploiement HTTPS

Pour obtenir une URL HTTPS, activez GitHub Pages dans le dépôt :
- Settings > Pages
- Source : Deploy from a branch
- Branch : main
- Folder : / (root)

Votre application sera alors disponible via une URL du type :
https://<votre-utilisateur>.github.io/al-studio/

## Fonctionnalités inclues

- Message de bienvenue personnalisé
- Météo du moment
- Look du jour
- Filtres de styles
- Calendrier de planning
- Gestion du dressing virtuel
- Ajout d’articles avec photo locale
- Installation sur mobile comme application native via navigateur

## Lancer localement

Ouvrez simplement `index.html` dans votre navigateur, ou lancez un petit serveur local :

```bash
python -m http.server 8000
```

Puis accédez à :
http://localhost:8000
